# Lei记账

自用的安卓自动记账 App。只适配**微信 + 支付宝**，以及**魅族 Flyme AIOS**（Android 11 及以上都能装）。

付完款后自动识别金额、商户和用途，用 DeepSeek 智能分类，每天、每周、每月推送收支总结。

## 工作原理

| 渠道 | 怎么做 | 耗电 |
|---|---|---|
| 通知监听 | 读取「微信支付」服务号和支付宝的扣款/到账通知 | 极低，有通知才唤醒 |
| 页面识别（无障碍） | 在「支付成功」页面读取金额、商户、支付方式。只接收微信和支付宝的界面事件 | 低，带防抖和关键词粗筛 |
| 截图 OCR 兜底 | 页面读不到文字时截一张图，用内置的 ML Kit 中文模型在本机识别 | 只在需要时触发，最多 4 秒一次 |
| 「识别记账」快捷开关 | 漏记时停在支付成功页，下拉通知栏点一下，读当前页面或截图识别 | 只在点击时运行 |
| DeepSeek | 把金额、商户和脱敏后的短文本发给 `deepseek-chat`，返回分类、商户名和用途 | 有网时由 WorkManager 批量处理 |

同一笔支付通常会被多个渠道同时捕获（页面 + 通知），`BillMerger` 会合并成一条：

- 不同渠道 5 分钟内、金额相同 → 合并；
- 同一渠道 90 秒内重复上报 → 合并；
- 超过窗口的同额账单（比如两次刷 ¥2 公交）→ 保留为两笔。

页面识别要求同时出现「支付成功 / 付款成功…」标题和「完成」按钮，所以聊天记录、账单详情页不会被重复记账。

## 安装

1. 打开本仓库的 **Actions** → 最新一次成功的 **Build APK** → 下载 `LeiAccounting-debug-apk`。
2. 解压得到 `app-debug.apk`，传到手机上安装。

## 首次设置（Flyme）

在 App 的「设置」页逐项打开：

1. **通知使用权**：必开。
2. **无障碍**：设置 → 无障碍 → 已下载的应用 → 「Lei记账 · 支付页面识别」。
   - 如果开关是灰色、提示「受限设置」：应用详情 → 右上角 ⋮ → 允许受限设置，然后再开。
3. **忽略电池优化**。
4. **魅族后台管理**：手机管家 → 权限管理 → 后台管理 → Lei记账 → 允许后台运行；同时打开「自启动」。不同 Flyme 版本菜单名可能略有不同。
5. **DeepSeek API Key**：在 [platform.deepseek.com](https://platform.deepseek.com) 创建并充值。每笔分类只有几百 token，一个月通常不到 1 元。
6. **微信 / 支付宝通知不要关**：系统「免打扰」不影响识别。但如果在微信里把「微信支付」公众号设成了「消息免打扰」，或在系统通知管理里关掉了微信/支付宝的通知，App 就不会发通知，也就读不到。不想被打扰的话，改成「静默 / 不弹横幅」。
7. **添加快捷开关**：下拉通知栏 → 编辑 → 把「识别记账」拖进来（Android 13+ 可在设置页一键添加）。
8. 可选：打开「在最近任务中隐藏」，后台卡片就看不到了，识别功能不受影响。

App 没有常驻前台服务。通知监听和无障碍服务由系统托管，不需要额外保活。

## 隐私

- 账单只存在本机数据库里，已关闭系统备份。
- 发给 DeepSeek 的只有金额、商户和不超过 400 字的原文；6 位以上的长数字（卡号、手机号、订单号）会先打码。截图不上传。
- 无障碍服务只读取，不点击、不操作任何界面。

## 排查漏记

设置页 →「查看识别日志」会列出收到的每条微信/支付宝通知、打开过的页面（类名和能读到几条文字）、截图识别的结果。微信聊天消息只记一句「收到过」，不记录联系人和内容。日志只存在本机，最多 500 条，可以一键分享。

## 已知限制

- **微信页面识别**：新版微信可能不让普通无障碍服务读取界面文字。这时 App 会自动改用截图 OCR；通知监听不受影响。
- 微信、支付宝改版后，页面文案可能变化，需要调整 `PageTextParser` 里的关键词。
- 支付宝不是每笔都推送通知，页面识别是它的主要渠道。

## 项目结构

```
core/   纯 Kotlin 逻辑（可单测）：通知/页面解析、金额提取、去重合并、分类规则、统计、DeepSeek 提示词
app/    Android：通知监听、无障碍服务、OCR、Room 数据库、WorkManager、Compose 界面
```

本地运行：`./gradlew :core:test :app:assembleDebug`（需要 JDK 17 和 Android SDK）。
